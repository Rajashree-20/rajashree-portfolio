# Personal Profile Website — Rajashree Vastrad

This folder contains the complete source files for the Personal Profile Website assignment.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — mobile menu and dynamic year
- `README.md` — setup and submission instructions

## How to run
1. Open the folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Before publishing, replace:
   - `your-email@example.com` with your real email
   - the LinkedIn link with your profile URL
   - the GitHub link with your profile URL

## How to publish
You can publish this website using:
- GitHub Pages
- Netlify
- Vercel

### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and copy the generated live website URL.
